# Marketing surface

## Signature

The evidence thread connects small context fragments to one inspectable outcome.
It may appear as a line, beam, path, or linked node structure, once per surface.

## Responsive

- Mobile: single-column narrative, no hover-only information, no ambient floating.
- Tablet: two-column content only when both columns remain readable.
- Desktop: split heroes and alternating rows; maximum content width remains 80rem.

## Edge cases

- Long Turkish headings balance and wrap without clipping.
- Capability status remains visible when cards stack.
- Generated images are decorative and use empty alt text.
- If product evidence cannot load, its caption still explains the mechanism.
