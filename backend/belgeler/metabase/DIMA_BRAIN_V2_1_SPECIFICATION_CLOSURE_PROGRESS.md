## 5. Conformance strategy

Create a **test-only**, small, declarative semantic specification package under
`backend/tests/semantic_spec/`.

It may model symbolic semantics such as `metric.m1`, `dimension.d1`, `entity.e1` and
`period.p1`, but it must not contain SQL, MBQL, Metabot cognition, business calculations or
LLM prompts. Runtime code must never import this package.

Coverage has three complementary layers:

- deterministic finite/pairwise semantic matrices;
- Hypothesis property testing;
- Hypothesis RuleBasedStateMachine sequences.

Correctness assertions must be independent semantic laws, not the production implementation
calling itself as its own oracle.
