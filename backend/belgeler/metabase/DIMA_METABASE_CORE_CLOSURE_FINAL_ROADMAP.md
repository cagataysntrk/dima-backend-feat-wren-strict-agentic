# CORE CLOSURE A — CLOSED-LOOP BRAIN + UX FOUNDATIONS

## A1. Internal Action Lifecycle / Work Tracking

Goal: convert an adopted/authorized decision into an internally trackable company commitment without any
external connector execution.

Target contract:

~~~text
DecisionAdoption
+ optional ActionAuthorization lineage
→ ActionWork / Commitment
→ owner
→ due date
→ status
→ blockers
→ completion reference
~~~

Minimum lifecycle:

~~~text
PLANNED
ACKNOWLEDGED
IN_PROGRESS
BLOCKED
COMPLETED
CANCELLED
~~~

Requirements:
- immutable or append-only lifecycle history;
- trusted tenant/principal binding;
- exact DecisionBrief / Adoption lineage;
- ActionAuthorization reference where relevant;
- owner and due-date identity;
- no connector call;
- no external side effect;
- completion does not itself prove business outcome.

This is work tracking, not execution.

## A2. Outcome Authority

Goal: close DECISION → ACTION/WORK → OBSERVATION without making Dima a second analytics engine.

Target flow:

~~~text
Decision / ActionWork
→ baseline definition
→ observation window
→ native Metabase / Metabot analytics
→ governed Evidence / Claim lineage
→ OutcomeObservation
~~~

Outcome may classify observed state, for example:

~~~text
IMPROVED
MIXED
WORSENED
NO_MATERIAL_CHANGE
INCONCLUSIVE
~~~

But permanent:

~~~text
OBSERVED IMPROVEMENT != ACTION CAUSED IMPROVEMENT
~~~

Causal attribution requires the existing epistemic authority. Outcome never computes local analytics.

Outcome must retain:
- source decision/action identities;
- expected state or target, if governed;
- baseline window;
- observation window;
- exact Evidence/Report references;
- limitations;
- currentness/staleness;
- no invented numeric value.

## A3. Institutional Memory

Canonical memory principle:

~~~text

+ context

+ currentness
~~~

Memory may link:

~~~text

~~~

Memory retrieval may help future Research or Decision context, but:
- old memory never overrides new governed Evidence;
- generated summaries are not truth authority;
- memory must point back to exact sealed source artifacts;
- vector similarity, if later used, is retrieval only.

## A4. Watch / Signal / Audit Core

Goal: make Dima proactive without rebuilding Metabase monitoring primitives.

Preferred flow:

~~~text

or governed Dima schedule/event
~~~

Dima owns:
- Watch identity and business intent;
- Signal identity;
- significance / materiality policy;
- links to entity, goal, open decision, work and memory;
- investigation-open decision;
- deduplication / cooldown / currentness.

Metabase owns analytical measurement where native capability exists.

Do NOT build a second generic metric polling engine merely to mirror Metabase.
