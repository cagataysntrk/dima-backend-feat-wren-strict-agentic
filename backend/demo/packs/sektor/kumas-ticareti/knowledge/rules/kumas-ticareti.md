# Kumaş ticareti sektör kuralları

- Ticaret şirketidir, üretim yoktur: "satış" = satış faturası, "alım" = mal alım
  faturası; stok hareketi fatura satırlarından izlenir.
- Miktar birimleri karışıktır (kg / metre / top) — birim kolonuna dikkat; toplam
  miktar sorularında birim ayrımı belirtilmeden toplanmaz.
- "Astar", "polyester", "parça" gibi terimler stok kartı adlarında geçer; ürün
  kırılımı stok kartı üzerinden yapılır.
